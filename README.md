# Movement Library

完全离线运行的个人训练动作知识库。当前版本 **V2.1**。

本仓库是项目的正式代码来源，后续功能、界面、维护脚本和说明均在此继续开发。项目独立于 Somaxis 微信小程序。

## 本机使用

Mac 用户双击 **[启动 Movement Library.command](启动%20Movement%20Library.command)**。需要本机有 Python 3，无需安装第三方依赖。也可在本目录运行：

```sh
python3 serve.py
```

浏览器地址固定为 **http://127.0.0.1:8774/index.html**。仅监听本机，不连接云服务；重复启动会打开已有服务。使用期间保留启动窗口。

## 当前功能

- 101 条 ACE IFT 原始记录；保留原名、原家族与模式，同名记录不自动合并。
- 卡片、列表、搜索、收藏和多维组合筛选。
- 肩胛骨独立分类；训练功能、器械和辅助标签按需填写。
- 家族目录、家族搜索及完整成员浏览。
- 点击动作先进入只读详情，直接浏览基础动作、变式、双向关联和同家族动作；编辑单独进入。
- 批量添加、移除、替换与清空；事务回滚、读回校验和超时反馈。
- 本地图片、视频、普通附件，以及包含附件的 JSON 备份。
- [Google Sheet课程动作录入模板与交接流程](templates/README.md)，支持随课程导入同步新增选项，保留已有动作。

## 数据保存与迁移

**GitHub 保存程序代码，不保存浏览器中的个人资料库。** 用户修改及附件存于本地 IndexedDB。请定期导出 JSON，并保留附件原文件。

固定使用同一浏览器、同一地址。不同端口、直接打开本地 HTML、不同浏览器的数据库彼此独立。从旧版迁移时，先在旧版导出 JSON，再在当前版导入。更新程序不需要清空数据库。

`original/` 是交接时提供的 V1.7 原文件及其 101 条内置记录，并非用户当前浏览器的个人备份。

## 开发

修改源文件后执行：

```sh
python3 upgrade.py
```

该步骤生成可独立分发的 `index.html` 和隔离测试页 `qa.html`。主页面不依赖网络、构建服务或第三方库。

| 文件 | 用途 |
| --- | --- |
| `extension.js` | 筛选、编辑、附件、备份等应用逻辑 |
| `navigation.js` | 家族目录、只读详情与关联浏览 |
| `intake.js` / `templates/` | 课程动作添加、选项字典与表格转换 |
| `ui.css` / `navigation.css` | 视觉与布局 |
| `upgrade.py` | 在原版基础上构建完整 HTML，保留原始种子数据 |
| `serve.py` | 本机启动与重复启动处理 |
| `qa.js` | 浏览器集成回归测试 |
| `original/` | 不修改的交接原件与原始记录 |

开发验证可运行 `python3 serve.py --no-open`，然后打开 http://127.0.0.1:8774/qa.html ，点击「运行浏览器测试」。测试使用独立的 `MovementLibraryV1-QA` 数据库，约需 15–20 秒，不修改日常数据库。`--port` 仅用于隔离测试，不要更换日常使用端口。
